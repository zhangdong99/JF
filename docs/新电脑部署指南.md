# 新电脑部署指南

前置要求：Windows 10/11、Git、Docker Desktop（WSL2）已安装并启动。

## 1. 克隆项目

```powershell
git clone https://github.com/zhangdong99/JF.git D:\Projects\AI-Office
cd D:\Projects\AI-Office
```

## 2. 准备运行数据目录（D 盘）

```powershell
New-Item -ItemType Directory -Force `
  D:\AI-Office\postgres, D:\AI-Office\n8n, D:\AI-Office\data\uploads, `
  D:\AI-Office\data\processing, D:\AI-Office\data\output, D:\AI-Office\data\archive, `
  D:\AI-Office\backups
```

## 3. 配置环境变量（密钥不进 Git，需手动填）

```powershell
# Docker 编排用（postgres + n8n + backend + frontend 共用）
Copy-Item docker\.env.example docker\.env
notepad docker\.env     # 填入真实密码与 N8N_ENCRYPTION_KEY
```

必填项：
- `POSTGRES_PASSWORD`（建议与下面 SQL 里的 n8n_user 密码一致管理）
- `N8N_DB_PASSWORD`（需与 `database/init/01-create-n8n.sql` 中的密码**一致**）
- `N8N_ENCRYPTION_KEY`（随机字符串；沿用旧电脑的值可直接继承 n8n 已保存的凭据）

同时检查 `database/init/01-create-n8n.sql` 中的密码与 `N8N_DB_PASSWORD` 一致。

## 4. 启动全部服务（首次会自动建表+导入种子数据）

```powershell
cd docker
docker compose -f compose.yaml -f compose.apps.yaml up -d --build
```

启动内容：
- postgres（数据落在 `D:\AI-Office\postgres`）
- n8n（数据落在 `D:\AI-Office\n8n`，http://localhost:5678）
- backend（自动 `alembic upgrade head` + 种子数据，http://localhost:8000/docs）
- frontend（http://localhost:8080）

## 5. 恢复 n8n 工作流（二选一）

方式 A（推荐，从 Git 里的备份导入）：

```powershell
docker cp workflows\n8n_system_import.json ai-office-n8n:/tmp/w1.json
docker cp workflows\n8n_plan_review.json ai-office-n8n:/tmp/w2.json
docker exec ai-office-n8n n8n import:workflow --input=/tmp/w1.json
docker exec ai-office-n8n n8n import:workflow --input=/tmp/w2.json
docker exec ai-office-n8n n8n list:workflow        # 记下两个 id
docker exec ai-office-n8n n8n update:workflow --id=<id1> --active=true
docker exec ai-office-n8n n8n update:workflow --id=<id2> --active=true
docker restart ai-office-n8n
```

方式 B（旧电脑有完整备份）：恢复 `D:\AI-Office\n8n` 整个目录后可直接继承工作流与凭据
（`N8N_ENCRYPTION_KEY` 必须与旧电脑一致）。

## 6. 配置 n8n 里的外部服务（界面操作）

1. 「邮件通知负责人」节点：配置 SMTP 凭据（不配也能用，只是不发邮件）
2. Ollama：确认本机已安装并 `ollama serve`，模型 `qwen3:8b` 已拉取
   （容器内访问地址为 `http://host.docker.internal:11434`）

## 7. 验证

| 检查 | 方法 | 预期 |
|---|---|---|
| 平台页面 | http://localhost:8080 | 总览看板有数据 |
| API | http://localhost:8000/api/v1/health | `{"code":0,...}` |
| 方案 | 方案管理 → 产品运营方案 | 种子方案存在 |
| AI 链路 | 方案详情提交一条领导意见 | 约 2 分钟后出现待确认建议 |

## 8.（可选）恢复旧数据

旧电脑的 `pg_dump` 备份：

```powershell
Get-Content ai_office_20261031.sql | docker exec -i ai-office-postgres psql -U admin -d ai_office
```

## 常见问题

- **端口冲突**：确认 5432/5678/8000/8080 未被其他程序占用
- **backend 起不来**：`docker logs ai-office-backend` 看日志，多为 .env 密码与 SQL 初始化不一致
- **n8n 调不到 Ollama**：确认宿主机 Ollama 在运行，防火墙未拦截 11434
- **改了 .env 不生效**：`docker compose -f compose.yaml -f compose.apps.yaml up -d --force-recreate`
